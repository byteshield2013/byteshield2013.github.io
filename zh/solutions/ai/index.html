AI Creative Studio

AI 视觉内容创作与编辑平台，让设计与行销团队更快将创意转化为视觉内容。AI Creative Studio 结合 AI 与节点式工作流程，透过图层、画布、AI 对话及非破坏式效果节点进行图片生成与视觉编辑，不需要建置模型或串接 API。从广告、社群到游戏与娱乐内容，让创意团队自由尝试不同风格与方向。

  • AI 图片生成与编辑 透过自然语言描述创作需求，快速生成图片、调整画面内容或延伸创意方向。
  • 图层式视觉工作流程 以熟悉的图层概念管理图片、文字与视觉元素，提升素材编辑与修改效率。
  • 节点式效果设计 利用非破坏式节点加入色彩、光影、模糊、扭曲及其他视觉效果，同时保留原始素材与后续调整弹性。
  • 即时预览与弹性修改 即时查看不同效果与参数的呈现结果，减少重复制作及来回修改的时间。

AI Model API Service

企业级生成式 AI 模型与 API 平台，将 AI 能力快速整合至产品、系统与企业流程。AI Model API Service 提供 Qwen 系列及多种第三方模型，支援文字、图片、音讯与影片等多模态应用，透过官方 API 或 OpenAI-compatible API 即可调用，不需自行建置推理基础设施。

  • 多模型 API 服务 依照效能、成本、延迟及应用需求，选择适合的 Qwen 或第三方模型。
  • 多模态 AI 能力 涵盖文字生成、视觉理解、图片生成、影片生成、语音辨识、语音合成及向量模型等应用。
  • OpenAI-compatible API 既有使用 OpenAI SDK 的应用，可透过修改 API Key、Base URL 及模型名称，降低模型迁移与整合门槛。
  • 用量监控与成本管理 查看模型调用量、Token 使用量、成功率、延迟及失败率，协助企业掌握服务品质与模型成本。
