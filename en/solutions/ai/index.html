AI Creative Studio

An AI visual content creation and editing platform that helps design and marketing teams turn ideas into visuals faster. AI Creative Studio combines AI with a node-based workflow: generate and edit images through layers, canvas, AI chat, and non-destructive effect nodes, with no model building or API work. From ad and social creatives to game and entertainment visuals, it gives creative teams room to explore styles and directions freely.

  • AI Image Generation and Editing Describe your creative needs in natural language to quickly generate images, adjust visuals, or extend creative directions.
  • Layer-Based Visual Workflow Manage images, text, and visual elements using a familiar layer concept, improving asset editing and revision efficiency.
  • Node-Based Effect Design Add color, lighting, blur, distortion, and other visual effects with non-destructive nodes, preserving the original asset and flexibility for further adjustments.
  • Real-Time Preview and Flexible Editing See the results of different effects and parameters instantly, reducing repeated production and back-and-forth revisions.

AI Model API Service

An enterprise-grade generative AI model and API platform that brings AI capabilities into your products, systems, and workflows fast. AI Model API Service offers the Qwen family and a range of third-party models with multimodal support across text, image, audio, and video, callable through the official API or an OpenAI-compatible API, no inference infrastructure required.

  • Multi-Model API Service Choose the right Qwen or third-party model based on performance, cost, latency, and application needs.
  • Multimodal AI Capabilities Covers text generation, visual understanding, image generation, video generation, speech recognition, speech synthesis, embedding models, and more.
  • OpenAI-Compatible API Applications already using the OpenAI SDK can lower the barrier to model migration and integration by simply changing the API key, base URL, and model name.
  • Usage Monitoring and Cost Management View model call volume, token usage, success rate, latency, and failure rate, helping enterprises track service quality and model costs.
  • Agent and Workflow Applications Depending on regional availability and feature rollout, models can be combined with knowledge bases, external tools, and workflows to build AI customer service, enterprise Q&A, and automated tasks. Some application development features currently have regional or preview limitations, actual adoption should be confirmed on a per-project basis.
